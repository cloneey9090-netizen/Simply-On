Perguntas frequentes

Dúvidas comuns de quem tá começando com o SimplyON.

É grátis? Preciso pagar algo?

O SimplyON é totalmente gratuito. Você só precisa ter conta em algum serviço de hospedagem (Netlify ou GitHub Pages), que também são gratuitos.

Preciso saber programar?

Não. Se você sabe usar WhatsApp, você consegue usar o SimplyON. Tudo é feito por botões e formulários simples.

Meus dados ficam salvos mesmo se eu fechar o app?

Sim. Todos os produtos, configurações e imagens ficam salvos no seu celular. Mesmo que o app seja fechado ou o celular reiniciado, seus dados continuam lá.

Funciona em iPhone (iOS)?

No momento o SimplyON é exclusivo para Android. Versão iOS pode chegar futuramente.

Como funciona a hospedagem?

Você configura seu token do Netlify ou GitHub uma vez. Depois, com 1 clique, o app envia seu catálogo pra web e te dá um link público pra compartilhar.

Posso usar meu próprio domínio?

Sim! Se você hospedar via Netlify ou GitHub Pages, pode apontar um domínio próprio depois. O app te dá o link padrão, mas nada impede você de configurar um domínio personalizado.
